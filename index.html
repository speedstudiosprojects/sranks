Compatibilidad

Un JAR, muchas versiones

SRanks está diseñado para correr en Spigot/Paper desde 1.7.10 hasta versiones modernas, con compatibilidad y degradación automática según la API disponible.

EntornoEstadoQué se comprueba
Paper 1.7.10 + Java 8ProbadoArreglo, compatibilidad legacy y carga del plugin.
Paper 1.8.8 + Java 8ProbadoGUI y requisitos sin mayor problema.
Paper 1.21.x + Java 21ProbadoCompatibilidad moderna con reflexión y fallbacks.
Paper 26.x + Java 25+ProbadoCompatibilidad con APIs nuevas y componentes recientes.
Primeros pasos

Instalación en minutos

Terminal
cp SRanks-1.0.0.jar plugins/
./start.sh
  1. Descarga el JAR y colócalo en plugins/.
  2. Arranca el servidor para generar los archivos iniciales.
  3. Instala dependencias opcionales si es necesario: Vault, PlaceholderAPI y LuckPerms.
  4. Configure los YAML y prueba con /sranks gui.

Progresión

Rangos y prestigios

YAML
ranks:
  aprendiz:
    order: 1
    requirements:
      money: 1000
    rewards:
      money: 250

La progresión se define por orden y requisitos combinados. Los prestigios trabajan como una segunda capa de avance.

Apariencia

GUI configurable

La interfaz se puede personalizar por título, filas, ítems, estados y botones. Todo se adapta para que la documentación no rompa el diseño ni la navegación.

YAML
gui:
  title: "SRanks"
  rows: 6
Potencia

Editor in-game

El editor permite configurar rangos, requisitos y recompensas desde un menú, sin tener que tocar YAML manualmente.

Comando
/sranks editor
